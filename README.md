##  Descripción del Proyecto
**PagoVirtual** es una aplicación web diseñada para gestionar inscripciones, actividades deportivas/educativas, movimientos y pagos de socios o alumnos, contando con acceso diferenciado por roles (Administrador, Entrenador y Usuario).

##  Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript
* **Base de Datos y Backend:** Supabase (PostgreSQL)
* **Control de Versiones y Despliegue:** Git, GitHub y Vercel

##  Estructura de la Base de Datos
El sistema cuenta con las siguientes tablas principales en PostgreSQL:
* `usuarios`
* `actividades`
* `inscripciones`
* `pagos`
* `movimientos`
* `administradores`
* `entrenadores`
